# Personal Finance AI Agent

## About the Project

Managing personal finances becomes easier when you can understand your expenses, plan a budget, estimate loan repayments, and calculate potential investment returns in one place.

I built this Personal Finance AI Agent using Python, Streamlit, LangChain concepts, and machine learning. The application allows users to ask financial calculation questions in natural language and receive responses supported by dedicated calculation functions.

Instead of relying entirely on an AI model for mathematical answers, the application performs financial calculations through Python functions and can use an LLM to explain the results in a more conversational way.

The project also includes a machine learning module that assesses financial health using income, expenses, loan EMIs, savings, and calculated financial ratios.

## Project Objectives

The main goals of this project are to:

- Build an interactive personal finance assistant.
- Calculate loan EMIs and estimated investment returns.
- Help users organize their income using the 50-30-20 budgeting rule.
- Handle basic mathematical and percentage calculations.
- Integrate language models for conversational financial explanations.
- Develop a machine learning interface for financial health and risk assessment.
- Deploy the functionality through a Streamlit application.

## Key Features

### 1. AI-Powered Financial Assistant

Users can enter financial questions in everyday language. The application identifies the type of calculation required and directs the request to the appropriate function.

Supported queries include loan repayment calculations, investment projections, budget planning, and general arithmetic.

### 2. Loan EMI Calculator

The EMI calculator estimates the monthly installment for a loan using the principal amount, annual interest rate, and repayment period.

It also calculates:

- Monthly EMI
- Total interest payable
- Total repayment amount
- Loan principal and repayment tenure

The application uses the reducing-balance EMI formula.

### 3. SIP Investment Calculator

The SIP calculator estimates the future value of regular monthly investments based on an assumed annual return and investment period.

It displays the estimated future value, total amount invested, and potential wealth gain.

These figures are projections based on the selected return assumption, not guaranteed investment outcomes.

### 4. 50-30-20 Budget Planner

The budget planner divides monthly income into three categories:

- 50% for needs, such as rent, groceries, and essential bills.
- 30% for wants, such as shopping, entertainment, and other lifestyle expenses.
- 20% for savings and investments.

This provides a simple starting point for organizing monthly finances.

### 5. Machine Learning Financial Health Assessment

The application includes a financial health assessment module built around a trained Random Forest classifier.

Users can enter their monthly income, living expenses, existing loan EMIs, and savings or investments. The application calculates additional indicators, including the debt-to-income ratio, savings rate, and monthly surplus.

The trained model then classifies the financial profile into one of three categories:

- Low financial risk
- Moderate financial risk
- High financial risk

The assessment depends on the supplied model and scaler files, `model.pkl` and `scaler.pkl`. Its predictions should be treated as indicative results rather than professional financial advice.

### 6. Multiple LLM Provider Options

The application provides options for different response-generation setups:

- Deterministic Financial Agent for offline calculations
- OpenRouter for supported models
- OpenAI
- Groq

When a configured language model is available, it can explain the results generated by the calculation functions. If the LLM request fails, the application is designed to fall back to its calculation-based response.

API access and model availability depend on the selected provider and its current terms.

### 7. Interactive Streamlit Interface

The application organizes its functionality into four main sections:

- AI Finance Agent
- Machine Learning Financial Health Predictor
- Interactive Financial Calculators
- System Overview and Architecture

It also includes sample queries, calculation summaries, charts, provider settings, and chat history controls.

## How the Application Works

The overall workflow follows these steps:

1. The user enters a financial question or selects a sample query.
2. The application identifies the likely calculation category.
3. The relevant Python function performs the calculation.
4. The application prepares the calculated result for display.
5. If an LLM provider is configured, the model can generate a conversational explanation based on the calculated result.
6. The response appears in the Streamlit chat interface.

For financial health assessment, the user enters financial details separately. The application calculates the relevant ratios, scales the features using the saved scaler, and passes them to the trained classification model.

## Installation and Setup

### 1. Clone the Repository

```bash
git clone <your-repository-url>
cd Personal-Finance-AI-Agent
```

Replace `<your-repository-url>` with your actual GitHub repository URL.

### 2. Create a Virtual Environment

```bash
python -m venv venv
```

Activate it on Windows:

```bash
venv\Scripts\activate
```

### 3. Install Dependencies

Install the packages required by the application. A typical starting point is:

```bash
pip install streamlit pandas numpy scikit-learn joblib openai langchain
```

Check the notebook and application imports before finalizing `requirements.txt`, since additional packages may be required by the full environment.

### 4. Add the Required Model Files

Place `model.pkl` and `scaler.pkl` in the location expected by the application. Both files are required for the machine learning assessment to run successfully.

### 5. Configure an LLM Provider

The application supports a deterministic calculation mode as well as supported LLM providers.

For API-based responses, obtain an API key from your chosen provider. Set the relevant environment variable, such as `OPENAI_API_KEY`, `OPENROUTER_API_KEY`, or `GROQ_API_KEY`, or enter the key through the application's provider settings.

Never upload real API keys to GitHub or commit them directly to source code.

### 6. Run the Application

```bash
streamlit run app.py
```

Streamlit will provide a local URL where you can open the application in your browser.

## Important Notes and Limitations

- SIP calculations use assumed returns. Actual market returns can be higher or lower, and investments can lose value.
- EMI estimates depend on the supplied interest rate and tenure and may differ from a lender's final repayment schedule.
- The financial health classifier depends on the training data, feature definitions, saved model, and scaler. Its predictions are not a substitute for a comprehensive financial review.
- Natural-language parameter extraction relies on the application's parsing logic. Review the extracted inputs when precision matters.
- API-based explanations require a valid key, supported model, and available service.
- The application does not connect to bank accounts or automatically retrieve real financial transactions.
